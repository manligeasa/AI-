# 톡톡예절 — 확인 및 출시 안내

> 요약: **확인**은 휴대폰에 'Expo Go' 앱을 깔고 QR 코드를 찍으면 바로 된다(무료).
> **출시**는 설치 파일(APK)을 만들어 **링크로 나눠 주는 방법(무료)** 으로 진행한다. 스토어 출시는 3장에 참고로 남겨 두었다.

---

## 1. 내 휴대폰에서 확인하기 (무료, 약 10분)

### 준비물
- 컴퓨터: Node.js(자바스크립트 실행 프로그램) LTS 버전 — https://nodejs.org 에서 설치
- 휴대폰: **Expo Go** 앱 — 플레이스토어·앱스토어에서 무료 설치
- 컴퓨터와 휴대폰이 **같은 와이파이**에 연결

### 순서
```bash
git clone https://github.com/manligeasa/AI-.git
cd AI-
git checkout claude/react-native-app-setup-4xzgvh
cd mobile
npm install          # 필요한 부품 내려받기 (처음 한 번)
npx expo start       # 화면에 QR 코드가 뜬다
```
- **안드로이드**: Expo Go 앱 → 'Scan QR code' → 컴퓨터 화면의 QR 코드 찍기
- **아이폰**: 기본 카메라로 QR 코드 찍기 → 'Expo Go에서 열기'
- QR을 찍어도 안 열리면(회사·학교 와이파이 등): `npx expo start --tunnel`
- 컴퓨터 브라우저로 미리 보기만 하려면: `npm run web`

### 확인 목록
| 탭 | 확인할 것 |

| 상황극 | 정답을 누르면 네온 파티클, 5문제 끝나면 스탬프 팝업 |
| 오디오 | '듣기'를 누르면 한국어로 읽고 빛 고리가 퍼짐 (무음 모드 해제) |

번역 빠짐 검사: `npm run check:i18n`

## 2. 링크로 나눠 주기 (선택한 출시 방법, 무료)

앱 이름: **톡톡예절** / 패키지 이름: `com.manligeasa.toktokyejeol` (`app.json`에 반영 완료)

### 2-1. 설치 파일(APK) 만들기 — 강사가 한 번
```bash
npm install -g eas-cli   # 처음 한 번
eas login                # expo.dev 무료 회원가입 후 로그인
cd mobile
eas build -p android --profile preview
```
- 처음 실행하면 몇 가지를 묻는다. 모두 **Enter(기본값)** 로 넘어가면 된다. EAS 프로젝트 연결, 서명 키(앱 주인 확인용 열쇠) 만들기 등이다.
- 10~20분 뒤 터미널과 expo.dev 화면에 **다운로드 링크와 QR 코드**가 나온다.
- **링크는 일정 기간이 지나면 받을 수 없게 될 수 있다.** APK 파일을 한 번 내려받아 구글 드라이브 등에 올리고, 그 공유 링크를 나눠 주는 것이 안전하다.
- 서명 키는 EAS에 저장된다. 다음 버전도 같은 계정으로 빌드해야 기존 앱 위에 업데이트로 설치된다.

### 2-2. 수강생 설치 안내 (안드로이드) — 그대로 나눠 주세요
1. 받은 **링크를 누르거나 QR 코드를 카메라로 찍는다.**
2. `톡톡예절.apk`(또는 비슷한 이름) **다운로드**를 누른다.
3. 다운로드가 끝나면 알림을 누르거나 '내 파일 → 다운로드'에서 파일을 누른다.
4. "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다"가 나오면 **설정 → '이 출처 허용' 켜기 → 뒤로 가기**를 누른다.
5. **설치**를 누른다. 'Play 프로텍트' 경고가 나오면 **'무시하고 설치'**(또는 '세부정보 → 설치')를 누른다.
6. 홈 화면의 **톡톡예절** 아이콘을 눌러 시작한다.

> 아이폰은 링크 설치가 되지 않는다. 아이폰 사용자는 강의 중 Expo Go로 보여 주거나, 나중에 앱스토어 출시를 검토한다.

### 2-3. 내용을 고친 뒤 새 버전 나눠 주기
1. `app.json`의 `"version"`을 올린다 (예: `1.0.0` → `1.0.1`).
2. `eas build -p android --profile preview`를 다시 실행한다.
3. 새 링크를 나눠 준다. 수강생이 설치하면 **기존 앱 위에 덮어써지고, 모은 스탬프와 설정은 그대로 남는다.** 같은 EAS 계정으로 빌드했을 때만 그렇다.

### 앱 아이콘
- 네온 말풍선에 '톡톡' 글자를 넣은 아이콘을 `mobile/assets/`에 넣어 두었다. 홈 화면 아이콘, 안드로이드 적응형 아이콘(바탕·앞그림·단색), 시작 화면, 웹 아이콘이다.
- 원본 그림: `mobile/assets/icon-source.svg`. 고치고 싶으면 이 파일을 디자인 도구에서 열어 수정한 뒤 같은 크기의 PNG로 다시 저장한다.

## 3. 나중에 스토어에 올리고 싶다면 (참고)
- **구글 플레이**: 개발자 등록 1회 25달러 → `eas build -p android --profile production` → `eas submit -p android`
  - '데이터 보안' 설문은 "수집하는 데이터 없음"으로 답한다.
  - 개인 계정은 정식 출시 전에 비공개 테스트가 필요하다(테스터 약 12명, 14일. 정책은 Console에서 확인).
- **애플 앱스토어**: 연 99달러 → `eas build -p ios --profile production` → `eas submit -p ios` → 심사
- 스토어는 개인정보처리방침 주소를 요구할 수 있다. "수집 정보 없음, 기록은 기기 안에만 저장"이라는 짧은 안내 페이지 하나면 된다.
