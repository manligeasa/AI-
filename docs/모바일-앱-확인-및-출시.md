# 모바일 앱 확인 및 출시 안내

> 요약: **확인**은 휴대폰에 'Expo Go' 앱을 깔고 QR 코드를 찍으면 바로 된다(무료).
> **출시**는 ① 설치 파일(APK)을 만들어 링크로 나눠 주는 방법(무료)과 ② 구글 플레이·애플 앱스토어에 올리는 방법(유료 계정 필요)이 있다.

---

## 1. 내 휴대폰에서 확인하기 (무료, 약 10분)

### 준비물
- 컴퓨터: Node.js(자바스크립트 실행 프로그램) LTS 버전 — https://nodejs.org 에서 설치
- 휴대폰: **Expo Go** 앱 — 플레이스토어·앱스토어에서 무료 설치
- 컴퓨터와 휴대폰이 **같은 와이파이**에 연결

### 순서
```bash
git clone https://github.com/manligeasa/AI-.git
cd AI-
git checkout claude/react-native-app-setup-4xzgvh
cd mobile
npm install          # 필요한 부품 내려받기 (처음 한 번)
npx expo start       # 화면에 QR 코드가 뜬다
```
- **안드로이드**: Expo Go 앱 → 'Scan QR code' → 컴퓨터 화면의 QR 코드 찍기
- **아이폰**: 기본 카메라로 QR 코드 찍기 → 'Expo Go에서 열기'
- QR을 찍어도 안 열리면(회사·학교 와이파이 등): `npx expo start --tunnel`
- 컴퓨터 브라우저로 미리 보기만 하려면: `npm run web`

### 확인 목록
| 탭 | 확인할 것 |
| --- | --- |
| 상황극 | 정답을 누르면 네온 파티클, 5문제 끝나면 스탬프 팝업 |
| 오디오 | '듣기'를 누르면 한국어로 읽고 빛 고리가 퍼짐 (무음 모드 해제) |
| 퀴즈 | 스피드 OX 10초 타이머·오답 팝업 / 봉투 스티커 끌어 놓기 |
| 소통 카드 | 체크하면 큰 네온 문구, 조문 순서 카드 넘기기 |
| 공통 | 한국어 문장 길게 누르기 → 모국어 힌트, 🌏 언어 바꾸기, 🏅 스탬프판 |

번역 빠짐 검사: `npm run check:i18n`

## 2. 출시하기

### 출시 전에 꼭 정할 것
1. **앱 이름**: 지금은 `app.json`의 `"name": "AI 질문 코치"`(처음 이름)다. 내용이 생활 예절·소통 앱으로 바뀌었으니 새 이름으로 고친다.
2. **앱 아이콘**: 지금은 Expo 기본 아이콘이다. `assets/icon.png`(1024×1024)와 `assets/android-icon-*.png`를 바꾼다.
3. **패키지 이름**: `com.manligeasa.aiquestioncoach`로 넣어 두었다. 스토어에 **한 번 올리면 바꿀 수 없으니** 바꾸려면 첫 업로드 전에 `app.json`에서 고친다.
4. **개인정보처리방침**: 이 앱은 서버로 아무 정보도 보내지 않는다. 그래도 스토어에서 주소(URL)를 요구할 수 있으니 "수집하는 개인정보 없음, 모든 기록은 기기 안에만 저장"이라는 짧은 안내 페이지를 하나 만들어 둔다.

### 공통 준비: EAS(Expo의 클라우드 빌드 서비스) — 무료 요금제로 가능
```bash
npm install -g eas-cli
eas login            # expo.dev 무료 회원가입 후 로그인
cd mobile
```
`eas.json`(빌드 설정 파일)은 미리 만들어 두었다.
- `preview`: 시험용 APK(안드로이드 설치 파일)
- `production`: 스토어 제출용

### 방법 ① 설치 파일을 링크로 나눠 주기 (안드로이드, 무료) — 수강생 시범 운영에 추천
```bash
eas build -p android --profile preview
```
- 10~20분 뒤 다운로드 링크와 QR 코드가 나온다.
- 수강생은 링크를 눌러 APK를 받고 '출처를 알 수 없는 앱 설치 허용'을 켠 뒤 설치한다.
- 아이폰은 이 방법이 불가하다(애플 개발자 계정 필요).

### 방법 ② 구글 플레이 스토어
1. Google Play Console 개발자 등록 (**1회 25달러**)
2. 스토어용 파일 만들기: `eas build -p android --profile production`
3. Play Console에서 앱 만들기 → 스토어 등록정보(설명·스크린샷·아이콘) 작성
4. '데이터 보안' 설문: 수집·공유하는 데이터 **없음**으로 답한다
5. 파일 올리기: `eas submit -p android` (또는 Console에 직접 업로드)
6. **개인 계정은 정식 출시 전에 비공개 테스트가 필요하다**(테스터 약 12명, 14일 — 정책이 바뀔 수 있으니 Console 안내를 확인). 수강생을 테스터로 모으면 된다.
7. 프로덕션 출시 신청 → 심사(보통 며칠)

### 방법 ③ 애플 앱스토어
1. Apple Developer Program 가입 (**연 99달러**)
2. `eas build -p ios --profile production` (맥 컴퓨터가 없어도 된다. 인증서는 EAS가 안내에 따라 만들어 준다)
3. `eas submit -p ios` → App Store Connect에서 설명·스크린샷 작성
4. 앱 개인정보 항목: '데이터를 수집하지 않음'
5. 심사 제출 → 보통 1~3일

### 업데이트할 때
- 내용 수정 → `eas build`로 새 파일 만들기 → 다시 제출 (버전 번호는 자동으로 올라간다)
