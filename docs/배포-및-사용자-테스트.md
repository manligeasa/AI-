# 배포와 사용자 테스트 안내

## 1. 배포 방법

### 방법 A. 바로 공유 — claude.ai 아티팩트 (현재 사용 중)

- 주소: https://claude.ai/artifact/M7KDRaD5f5m84BQA2ih7cU
- 처음에는 **나만 볼 수 있다**. 테스트 참가자에게 보내려면 페이지의 **공유(Share) 메뉴**에서 공개 범위를 바꾼다.
- 앱을 고친 뒤 다시 올릴 때: `npm run build:artifact` → `dist-artifact/ai-question-coach.html`을 같은 주소로 다시 게시한다.

### 방법 B. 정식 배포 — Vercel (무료, 내 주소로 운영)

Vercel(만든 웹사이트를 인터넷에 올려 주는 서비스)은 이 앱(Vite)을 자동으로 알아본다. 별도 설정 파일이 필요 없다.

1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New → Project** → 이 저장소 선택
3. 설정은 그대로 두고 **Deploy** 클릭 (Build: `npm run build`, 결과 폴더: `dist`)
4. 1~2분 뒤 `https://○○○.vercel.app` 주소가 생긴다
5. 이후 GitHub에 올릴 때마다 자동으로 새 버전이 배포된다

> 나중에 OpenAI를 연결할 때도 Vercel이 편하다. API 키를 Vercel의 환경 변수(서버에만 보관하는 비밀 설정)에 넣고 `/api/analyze` 서버 기능을 추가하면 된다.

## 2. 사용자 테스트 계획

- **대상**: 50~70대 AI 입문자 3~5명 (강의 수강생, 지인)
- **시간**: 1인당 15분
- **방식**: 휴대폰으로 링크를 열고, 진행자는 옆에서 **도와주지 않고 관찰만** 한다

### 과제 (순서대로 부탁하기)

1. "AI에게 평소 하고 싶던 질문을 적고 평가를 받아 보세요."
2. "점수가 왜 그렇게 나왔는지 말로 설명해 주세요."
3. "더 좋은 질문을 복사해서 ChatGPT(또는 Claude)에 붙여 넣어 보세요."
4. "입력한 내용을 지우고, 예시 버튼 하나를 눌러 다시 해 보세요."
5. 아래 테스트 질문 5개를 차례로 넣어 보기

### 테스트 질문과 현재 결과 (규칙 기반 1차 버전)

| 테스트 질문 | 점수 | 수준 | 충족 항목 | 개선 질문에 붙는 역할 |
|---|---|---|---|---|
| 칼럼 써줘 | 33점 | 기초 | 목적, 형식 | 신문 칼럼니스트 |
| 유튜브 만들어줘 | 17점 | 기초 | 목적 | 유튜브 콘텐츠 작가 |
| AI 강의안 만들어줘 | 17점 | 기초 | 목적 | 경험 많은 교육 전문 강사 |
| 정치 댓글 써줘 | 17점 | 기초 | 목적 | SNS 글쓰기 전문가 + 존중 표현 요청 |
| 태안 파크골프 대회 홍보문 만들어줘 | 17점 | 기초 | 목적 | 지역 행사 홍보 전문가 |

테스트 전에 확인하고 고친 점:
- 칼럼·홍보문에 "친절한 전문가"라는 막연한 역할이 붙던 것을 분야에 맞게 바꿨다.
- 정치·종교처럼 민감한 주제에는 "사실에 근거하고, 생각이 다른 사람도 존중하는 표현으로 써줘"를 자동으로 덧붙인다.

### 끝나고 물어볼 질문 5가지

1. 가장 도움이 된 부분은 무엇이었나요?
2. 이해가 안 되거나 헷갈린 말이 있었나요?
3. 점수가 내 생각과 달랐던 적이 있나요?
4. 개선된 질문을 실제로 써 보고 싶나요? 어디에 쓰고 싶나요?
5. 친구에게 추천한다면 뭐라고 소개하겠어요?

### 테스트 후 판단 기준

- 5명 중 **4명 이상**이 도움 없이 끝까지 사용 → 다음 단계(OpenAI 연결)로 진행
- 같은 곳에서 **2명 이상** 막힘 → 그 화면의 문구·버튼부터 고친다
- "점수가 이상하다"는 의견 → 해당 질문을 모아 키워드(`src/services/ruleEngine/keywordAnalyzer.js`)에 추가한다
