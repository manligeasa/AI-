# AI 질문 코치 — MVP 설계안

## 한 줄 요약

사용자가 질문을 넣으면 **① 5가지 기준으로 진단 → ② 빠진 정보를 쉬운 선택지로 물어봄 → ③ 더 좋은 질문 3가지를 만들어 줌 → ④ 복사해서 바로 사용**하는 앱이다.

- 대상: AI 초보자, 50~70대, 프리랜서, 강사, SNS 글쓰기 사용자
- 원칙: 한 화면에 한 가지 일, 전문 용어 없음, 큰 글씨·큰 버튼, 칭찬 먼저

---

## 1. MVP 기능 목록

MVP(최소 기능 제품, 꼭 필요한 기능만 담은 첫 버전)는 아래 6가지로 한정한다.

| 우선순위 | 기능 | 설명 |
|---|---|---|
| 필수 | ① 질문 입력 | 큰 입력창 1개. 예시 문장 버튼으로 바로 채워 볼 수 있음 |
| 필수 | ② 질문 진단 | 5가지 기준을 신호등(초록/노랑/빨강)으로 표시하고, 이유를 한 문장으로 설명 |
| 필수 | ③ 빈칸 채우기 도우미 | 빠진 정보를 객관식 버튼으로 물어봄 (예: "누가 읽을 글인가요? 친구 / 수강생 / 고객") |
| 필수 | ④ 개선 질문 만들기 | 짧게 / 보통 / 자세히 3가지 버전 제공, 무엇이 바뀌었는지 색으로 표시 |
| 필수 | ⑤ 복사하기 | 버튼 한 번으로 복사, "ChatGPT·Claude에 붙여넣으세요" 안내 |
| 권장 | ⑥ 상황별 예시 모음 | 강의 준비 / SNS 글 / 업무 메일 / 일상 생활 4개 분야의 좋은 질문 예시 |
| 권장 | ⑦ 내 질문 기록 | 로그인 없이 기기에 최근 질문 10개 저장 |

### 진단 기준 5가지 (쉬운 말 버전)

| 기준 | 사용자에게 보이는 말 | 확인하는 것 |
|---|---|---|
| 목적 | 무엇을 원하나요? | 요약·작성·추천 등 원하는 일이 분명한가 |
| 배경 | 어떤 상황인가요? | 필요한 사정·조건이 들어 있는가 |
| 대상 | 누구를 위한 건가요? | 읽는 사람·듣는 사람이 정해져 있는가 |
| 형식 | 어떤 모양으로 받을까요? | 분량, 목록/표/문단 등 결과 형태 |
| 말투 | 어떤 느낌으로 쓸까요? | 존댓말, 친근함, 전문적 등 분위기 |

- 점수는 숫자 대신 **별 5개**로 보여 준다 (초보자가 부담 없이 받아들이도록).
- 진단 문구는 항상 "잘한 점 1개 → 보완할 점"의 순서로 쓴다.

### MVP에서 제외 (다음 버전)

- 회원가입·로그인, 결제
- 음성 입력 (2차 버전 1순위 후보)
- 강사용 수업 모드 (수강생 질문 모아 보기)
- 커뮤니티·공유 기능

## 2. 화면 구성

전체 흐름:

```
[1. 홈] → [2. 질문 입력] → [3. 진단 결과] → [4. 빈칸 채우기] → [5. 개선 질문] → 복사
                ↑                                                    │
          [6. 예시 모음]                                     [7. 내 기록]에 자동 저장
```

### 화면 1. 홈

- 큰 제목: "AI에게 더 잘 묻는 법, 함께 연습해요"
- 큰 버튼 2개: **[질문 고쳐 보기]** / **[좋은 질문 예시 보기]**
- 하단: 3단계 사용법 그림 (입력 → 진단 → 완성)

### 화면 2. 질문 입력

- 큰 입력창 1개 + 안내 문구 "AI에게 하고 싶은 말을 그냥 적어 보세요"
- 분야 선택 칩(작은 버튼): 강의 준비 / SNS 글 / 업무 / 일상
- 예시 문장 버튼: "블로그 글 써줘" 같은 짧은 예시를 눌러 바로 체험
- **[진단받기]** 버튼 (화면 폭 전체 크기)

### 화면 3. 진단 결과

- 맨 위: 별점 + 한 줄 총평 ("목적은 분명해요! 대상만 더하면 훨씬 좋아져요")
- 5가지 기준 카드: 신호등 색 + 한 문장 이유
- 다음 버튼: **[빠진 부분 채우기]** / (바로 보고 싶은 사람용) **[바로 고친 질문 보기]**

### 화면 4. 빈칸 채우기 도우미

- 빨강·노랑 항목만 한 번에 하나씩 질문
- 답은 버튼 선택 위주, 필요할 때만 짧게 직접 입력
- 진행 표시: "2 / 3"
- 건너뛰기 가능

### 화면 5. 개선 질문

- 탭(선택 버튼) 3개: **짧게 / 보통 / 자세히**
- 원래 질문 대비 추가된 부분을 형광펜 색으로 표시
- "왜 더 좋아졌나요?" 설명 3줄
- 버튼: **[복사하기]** / **[다시 고치기]** / **[처음으로]**

### 화면 6. 예시 모음

- 분야별 카드: 나쁜 질문 → 좋은 질문 비교
- **[이 질문으로 연습하기]** 누르면 입력 화면으로 이동

### 화면 7. 내 기록

- 최근 질문 목록 (날짜, 별점 변화: ★★ → ★★★★★)
- 누르면 개선 질문 다시 보기·복사

## 3. 50~70대를 위한 화면 원칙

1. **글자 18px 이상**, 버튼 높이 56px 이상, 글자 크기 키우기 버튼 제공
2. **한 화면 한 가지 일**: 스크롤과 선택지를 최소화
3. **전문 용어 금지**: "프롬프트" 대신 "질문", "컨텍스트" 대신 "상황 설명"
4. **실수해도 괜찮은 구조**: 모든 화면에 [뒤로] [처음으로] 버튼
5. **칭찬 먼저**: 진단 결과는 항상 잘한 점부터 보여 줌

---

## 4. 기술 구성 제안 (MVP)

- 화면: Next.js (웹사이트를 만드는 도구) — 휴대폰·PC 모두 대응
- AI: Claude API (AI 기능을 앱에 연결하는 통로) — 진단과 개선 질문 생성을 한 번의 요청으로 처리해 비용 절감
- 저장: 브라우저 저장소 (기기 안에 기록 보관, 서버·로그인 불필요)
- 배포: Vercel (만든 웹사이트를 인터넷에 올려 주는 서비스)
