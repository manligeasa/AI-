# AI 질문 코치 — MVP 설계안

## 한 줄 요약

사용자가 질문을 넣으면 **① 6가지 기준으로 평가하고 → ② 개선된 질문 예시를 보여 주는** 앱이다.

- 대상: AI 초보자, 50~70대, 프리랜서, 강사, SNS 글쓰기 사용자
- 원칙: 한 화면에 한 가지 일, 전문 용어 없음, 큰 글씨·큰 버튼, 칭찬 먼저

---

## 1. 핵심 기능 3가지

MVP(최소 기능 제품, 꼭 필요한 기능만 담은 첫 버전)는 아래 3가지만 만든다.

| 순서 | 기능 | 설명 |
|---|---|---|
| 1 | 질문 입력 | 사용자가 AI에게 하고 싶은 질문을 입력한다 |
| 2 | 질문 평가 | 앱이 질문을 6가지 기준으로 평가한다 |
| 3 | 개선 질문 예시 | 앱이 평가 결과를 반영한 더 좋은 질문을 보여 준다 |

### 평가 기준 6가지

| 기준 | 사용자에게 보이는 말 | 확인하는 것 | 나쁜 예 → 좋은 예 |
|---|---|---|---|
| 1. 목적 | 무엇을 원하나요? | 요약·작성·추천 등 원하는 일이 분명한가 | "건강" → "건강 습관을 추천해줘" |
| 2. 상황 | 어떤 상황인가요? | 필요한 사정·배경이 들어 있는가 | → "60대이고 무릎이 약해" |
| 3. 대상 | 누구를 위한 건가요? | 읽는 사람·듣는 사람이 정해져 있는가 | → "복지관 수강생에게 나눠 줄" |
| 4. 역할 | AI가 누구처럼 답할까요? | AI에게 전문가 역할을 맡겼는가 | → "운동 강사처럼" |
| 5. 형식 | 어떤 모양으로 받을까요? | 분량, 목록/표/문단 등 결과 형태 | → "5가지를 번호로" |
| 6. 말투 | 어떤 느낌으로 쓸까요? | 존댓말, 친근함, 전문적 등 분위기 | → "쉽고 따뜻한 말투로" |

평가 표시 방법:
- 기준별로 **충분(초록) / 조금 부족(노랑) / 빠짐(빨강)** 3단계로 표시한다.
- 종합 점수는 숫자 대신 **별 5개**로 보여 준다 (초보자가 부담 없이 받아들이도록).
- 평가 문구는 항상 "잘한 점 1개 → 보완할 점" 순서로 쓴다.

### 개선 질문 예시 규칙

- 빨강·노랑 기준을 채워 넣은 질문 1개를 보여 준다.
- 원래 질문에서 **새로 더해진 부분을 형광펜 색으로 표시**해 무엇이 바뀌었는지 한눈에 보이게 한다.
- 사용자가 모르는 정보(나이, 대상 등)는 `[ ]` 빈칸으로 남겨, 직접 채워 쓰게 한다.
- [복사하기] 버튼으로 바로 가져갈 수 있게 한다.

### 다음 버전으로 미룬 기능

- 빈칸 채우기 도우미 (객관식으로 빠진 정보 묻기)
- 짧게/보통/자세히 3가지 버전
- 상황별 예시 모음, 내 질문 기록
- 회원가입·로그인, 음성 입력

## 2. 화면 구성 (3개)

```
[1. 질문 입력] → [2. 평가 결과] → [3. 개선 질문] → 복사
       ↑_______________ [다시 해보기] ______________|
```

### 화면 1. 질문 입력

- 제목: "AI에게 하고 싶은 질문을 그냥 적어 보세요"
- 큰 입력창 1개
- 예시 문장 버튼 2~3개 ("블로그 글 써줘", "강의 자료 만들어줘")를 누르면 입력창이 채워짐
- **[평가받기]** 버튼 (화면 폭 전체 크기)

### 화면 2. 평가 결과

- 맨 위: 별점 + 한 줄 총평 ("목적은 분명해요! 대상만 더하면 훨씬 좋아져요")
- 6가지 기준 카드: 신호등 색 + 한 문장 이유
- **[더 좋은 질문 보기]** 버튼

### 화면 3. 개선 질문

- 위: 내 원래 질문 (회색)
- 아래: 개선된 질문 (더해진 부분 형광펜 표시)
- "왜 더 좋아졌나요?" 설명 2~3줄
- 버튼: **[복사하기]** / **[다시 해보기]**

## 3. 50~70대를 위한 화면 원칙

1. **글자 18px 이상**, 버튼 높이 56px 이상
2. **한 화면 한 가지 일**: 스크롤과 선택지를 최소화
3. **전문 용어 금지**: "프롬프트" 대신 "질문", "컨텍스트" 대신 "상황 설명"
4. **실수해도 괜찮은 구조**: 모든 화면에 [뒤로] 버튼
5. **칭찬 먼저**: 평가 결과는 항상 잘한 점부터 보여 줌

---

## 4. 기술 구성 제안 (MVP)

- 화면: Next.js (웹사이트를 만드는 도구) — 휴대폰·PC 모두 대응
- AI: Claude API (AI 기능을 앱에 연결하는 통로) — 평가와 개선 질문을 한 번의 요청으로 받아 비용 절감
- 저장: 없음 (MVP는 기록 기능 제외)
- 배포: Vercel (만든 웹사이트를 인터넷에 올려 주는 서비스)
